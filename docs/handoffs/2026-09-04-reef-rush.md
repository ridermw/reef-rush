Task 5 review status: **needs fixes**.

Blocking findings:

1. `moveFish` uses sampled overlap checks and binary search instead of Rapier's required shape-cast query. Thin blockers can be missed.
2. Contact normals assume axis-aligned boxes even when tracked colliders are rotated, so slide projection can use the wrong plane.
3. Tracked collider transforms are creation-time snapshots. Moving, rotating, or removed dynamic colliders can be queried at stale positions.
4. `FishController` forwards water transition state and breach or splashdown events from unconstrained motion even when collision prevents the crossing.

Deferred minor findings:

- Rapier's Node test import prints experimental WebAssembly warnings.
- The local `src/three.d.ts` shim is too narrow for later renderer work and should be replaced with accurate library typings before Task 8 or 9.

## Decisions and rulings

- TypeScript is pinned to 6.0.3 because `typescript-eslint` 8.68.0 does not support TypeScript 7.

- `W/S` control throttle; arrow up/down control pitch. This avoids coupling forward speed to pitch.
