### Current asset and scene contracts

The exporter uses a fixed seed, explicit meters, glTF +Y up and game forward +Z.
The four self contained files have no external images or decoder dependency.
Budgets are 2 MiB per GLB, 5 MiB combined, 100,000 course triangles, 256 course
mesh nodes, and 10,000 fish triangles. Validation also caps decoded work before
allocating accessor arrays. These are technical caps, not art quality scores.

`CourseDefinition.visuals` is a strict generated/glTF union. The glTF variant
uses `visualAsset` and `collisionAsset`, relative to `public\assets`, with
canonical distinct paths. Sunlit requests exactly its visual GLB, collision
GLB, and `fish/sunfin.glb`, and only after the player starts loading a course.
The prop kit is already instanced into the course file and is not fetched again.

`staticSolidContract.mjs` shares pure primitive metadata/surface validation
between the offline validator and browser code. `validateLoadedCourseAsset.ts`
checks the loaded profile, identities, every static object, dimensions, world
transforms, geometry, winding, and closure. Existing CourseDefinition
primitives still drive Rapier. Neither loader disagreement nor failure silently
falls back to generated art.

`SceneRuntimeDependencies.createVisuals` can return `SceneVisuals` or a promise.
An optional `assetCache` supports isolated owned integrations. The default path
selects the original renderer for glTF definitions and retains generated
fixtures. Heavy imports remain in the lazy scene graph.

`createOriginalSceneVisuals` observes every acquisition with `allSettled` and
owns every successful late lease. Identical `ConstructionCleanupError` objects
from coalesced requests are deduplicated before registration. Mixers stop and
uncache before fish leases release. A failed child is retained for explicit
retry, never implicitly retried by the original catch. Existing GameHost
cancellation waits for loading and owns any late scene or cleanup error.

`createRaceMarkers`, `visualResources`, and `underwaterEnvironment` are shared
by original and generated rendering. Gates follow live Rapier transforms;
checkpoint and pearl feedback follows race state. Decorative mesh camera
exclusions are preserved while static solids remain obstructions. Scene
environment restoration and all resource releases remain retryable.

Sunfin swim and 56 deterministic ambient/current particles use bounded
presentation clocks, including for huge finite frame deltas. Paused/finished
presentation freezes them. Shared asset materials and clips remain immutable;
there is no new React frame state, simulation randomness, or postprocessing
dependency.

### Task 8 host and browser slice

`GameHost` is owned by main, not a transient screen. `setContainer` is a stable
React ref; detachment suspends the surface without abandoning its retry owner.
Only one canvas and animation chain may exist. Loading checks generations
after asynchronous boundaries; late resources are released, not attached.
`whenIdle()` and `dispose()` wait for loading and queued persistence. Failed
cleanup remains reachable through the host and `retryCleanup()`; new loading
is blocked until cleanup succeeds.

The fixed loop uses 1/60 second steps. Pause or finish aborts remaining catchup;
resume resets the wall timestamp and accumulator. Focus is checked before
attaching the canvas. Loading into an unfocused document pauses at zero time,
and focus return alone does not resume. Escape works on focused pause controls
without stealing native Space/Enter activation or editable input behavior.

Finishes display results immediately. Persistence takes the native Web Lock
`reef-rush.progress`, then synchronously reads current storage, merges it with
the latest session records, and writes through the protected storage helper.
`mergeProgress` takes minimum best time, maximum medal, and maximum pearl count
independently across the union of courses. Invalid current raw data remains
untouched. Missing coordination, unavailable storage, and write failures leave
session results visible with an explicit notice. Saving continues across title
navigation and disposal, but a blocked lock can delay awaiters.

Test builds expose only immutable observation through
`window.__REEF_RUSH_TEST__.getSnapshot()`. There are no teleport, clock, finish,
or input mutation actions. Normal production removes the hook. Three.js,
Rapier, course loading, and scene chunks remain lazy until a course is requested.

Review repairs covered stale saved records, loading focus loss, Escape on
buttons, and pointer movement through HUD/status panels. A browser image also
